# 🎨 宣传片素材文件夹（`promo_assets`）使用说明

把你想替换的图片直接放进这个文件夹里，**刷新 `promo_showcase.html` 就会自动生效**（支持 `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`，不需要改代码）。

> 如果某个文件还没放，页面会自动保留默认占位样式，不会报错或裂图。

---

## 📁 支持的素材文件名对照表

| 文件名（不含扩展名） | 用途与展示位置 | 建议尺寸 / 比例 |
| :--- | :--- | :--- |
| **`yuanji_avatar`** | 袁基头像（Act 1 通知横幅、Act 3 聊天头像、Act 4 情侣空间） | 1:1 正方形（如 `512×512`） |
| **`user_avatar`** | 你的头像（Act 4 情侣空间左侧头像） | 1:1 正方形 |
| **`lock_bg_1`** | 锁屏壁纸 1（Act 2 初始锁屏背景） | 9:16 竖屏 |
| **`lock_bg_2`** | 锁屏壁纸 2（Act 2 第 4.5 秒自动切换的诗签壁纸） | 9:16 竖屏 |
| **`sticker_1`** | 袁基活人感表情包（Act 3 聊天斗图，支持静态图或 `.gif` 动图） | 1:1 或横图 |
| **`stage_bg`** | 9:16 宣传片手机壳外面的剧场大背景（可选） | 9:16 竖屏 |
| **`app_logo`** | Act 6 片尾《鸢小手机》印章 Logo 图标（可选） | 1:1 正方形 |
| **`journal_img`** | Act 4 手账页面内嵌插图（可选） | 横图 / 4:3 |

---

## 💡 小贴士
* **命名时不用管后缀**：比如放 `yuanji_avatar.jpg` 或 `yuanji_avatar.png` 都可以，脚本会自动按 `png → jpg → jpeg → webp → gif` 顺序识别。
* 如果你放好了图但发现某张图的**文字颜色被背景吃掉了**（比如浅色壁纸配了白字），直接告诉我，我帮你调一下遮罩或文字对比度！

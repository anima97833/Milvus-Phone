## 一、核心能力评估：我能胜任哪些部分？

制作一部高质量的宣传片，本质上是 **「产品策划 + 视觉素材 + 实机录制 + 节奏剪辑 + 音频包装」** 的结合。以下是客观、透明的能力边界评估：

### ✅ 我非常胜任的工作（可由我主力推进）
1. **专业策划与分镜脚本**：基于代码库中的真实交互逻辑，提炼产品最抓人的记忆点（Hook），撰写逐秒分镜表、屏幕花字文案（OS）与转场设计。
2. **演示专用“完美存档”（Demo Seed）构建**：
   - 编写独立的演示数据注入脚本，在不污染你真实存档、不暴露个人 API Key 的前提下，自动填充高颜值壁纸、名士头像、高甜/搞笑聊天记录、14 页手账内容、捉迷藏战绩等，彻底杜绝录屏“空白占位/穿帮”。
3. **自动化丝滑实机录屏（Playwright / 浏览器自动化）**：
   - 手动用鼠标录屏容易出现手抖、点偏、等待 AI 回复卡顿等问题。我可以编写自动化脚本控制本地网页，以固定分辨率（如 `1080×1920` 或 `1920×1080`）、高帧率精准完成“滑动解锁 → 点开对话 → 触发表情包与微动效 → 翻动 `turn.js` 手账 → 切换子应用”的丝滑操作录制。
4. **程序化包装与粗剪合成**：
   - 可用前端代码构建**手机样机外框（Mockup）+ 动态字幕条 + 特征转场动画**；若本地环境支持 `FFmpeg` / Python，还能直接把多段录屏自动裁切、拼接、加转场并输出可审片的视频初稿。

### ⚠️ 需要你配合或使用外部工具的部分
1. **主观审美级精剪与复杂特效**：程序化脚本擅长“精准、规范、批量”，但难以替代人类在剪映 / PR / AE 中对“音乐卡点情绪张力、复杂 3D 摄像机运动、粒子光效”的直觉微调。**最佳实践是：我负责出全套分镜 + 丝滑无瑕疵的实机录屏片段/粗剪版，你（或剪辑工具）做最终卡点精修。**
2. **版权合规的 BGM 与角色配音**：我无法直接生成带特定声优音色的真人配音或商用授权音乐，需要你确认选曲或使用合规的 TTS/免版权素材库。
3. **同人美术与壁纸素材**：需要你提供统一画风的名士头像、锁屏壁纸、代表性表情包（避免出现空白占位图或版权争议图）。

## 二、已拍板方案与核心卖点提炼（Creative Brief）

> **已确认规格**：**竖屏 9:16** ｜ **出镜主角：袁基** ｜ **制作形态：可交互 HTML 宣传片样机网页（混合实机嵌入版）**

### 1. 为什么「可交互 HTML 宣传片样机」更适合你？
- **一物两用**：既是**全自动时间轴播放器**（全屏播放后直接录屏/Playwright 导出即为 9:16 高清成片），也是**可点击的网页互动展示页**。
- **改稿零成本**：调整花字文案、袁基台词、每幕节奏秒数只需改配置，无需反复重录重剪。
- **混合实机质感**：样机外框与电影级花字/转场由 HTML/CSS 驱动，复杂玩法（如 `turn.js` 翻页手账、捉迷藏）可通过隔离 Demo 存档的实机嵌屏呈现，兼顾“包装高级感”与“实机真实度”。

### 2. 目标受众
- **核心圈层**：《代号鸢》玩家（尤其袁基推）、同人二创/语C/OC 爱好者
- **泛圈层**：AI 虚拟陪伴重度用户、喜欢高自由度手机桌面 DIY / 电子手账的人群

### 3. 三大核心记忆点（结合袁基人设）
1. **温润表象下的“活人感”拉扯**
   - 依托表情包活人感强化、**灵犀生境情境微动效**（`live_reaction_engine.js`）与**构造状态气泡**（`construct_bubble_engine.js`），展现袁基“表面端方雅正、私下句句有回应/反差斗图”的真实陪伴感。
2. **新中式雅致桌面与物理翻页手账**
   - 贴合袁基的书卷茶香气质：PWA 桌面安装、古风诗签锁屏 DIY，以及基于 `turn.js` 实现的 **14 页真实物理翻页情侣手账**。
3. **把一整座“机中机宇宙”装进口袋**
   - 涵盖**情侣空间**（府邸捉迷藏贝叶斯听声辨位、飞花传令、我画你猜、风月传说、旧日食谱）与**独立子应用矩阵**（傩·观影时光、共听电台、今日学宫、自习室、OC 点单程序、街机/游戏厅）。

### 4. 建议输出规格（以 9:16 竖屏为核心）
| 版本 | 时长 | 画幅比例 | 适用平台 | 核心目标 |
| :--- | :---: | :---: | :--- | :--- |
| **主宣传片（标准 PV）** | 60–75 秒 | **9:16（竖屏）** | 小红书 / 抖音 / B站竖屏 | 全面展示袁基陪伴感、桌面美学与丰富玩法 |
| **快闪预告版（Teaser）** | 15–20 秒 | **9:16（竖屏）** | 抖音 / 小红书流量卡点 | 3 秒抓眼球，主打“手机里住着一个活人感袁基” |

## 三、你需要做的准备工作清单（Pre-Production Checklist）

在正式开工前，建议你按以下 5 类逐项确认并准备素材：

### 1. 定位与风格拍板
- [ ] **首选发布平台与画幅**：主推竖屏（9:16，贴合手机原生观感）还是横屏（16:9，适合多机同框对比与文字排版）？
- [ ] **整体视觉基调**：
  - *方案 A（推荐）*：**新中式国风雅致**（暖米白底色 `#fffcf7` + 黛青/莫兰迪点缀，与 `index.html` 现有设计语言一致）
  - *方案 B*：**高能赛博/少女心桌面风**（贴纸感、快节奏卡点）

### 2. 出镜角色与视觉素材包
- [ ] **选定 1–2 位“主角名士”**：建议 1 位主推名士贯穿全片（如展示聊天、捉迷藏、手账），1 位辅助名士展示多角色切换。
- [ ] **准备统一画风素材**（放进专属 `promo_assets/` 文件夹即可）：
  - 高清锁屏壁纸 2–3 张（竖屏 9:16，避开人物面部被时钟遮挡）
  - 玩家“我”的头像 + 伴侣名士头像
  - 6–10 张极具“活人感”的搞笑/心动表情包（用于演示聊天斗图）
  - 2–3 张可用于“手账达人”贴纸或“今日食谱”的精美插图

### 3. 脱敏演示剧本（Demo Script）
- [ ] **编写 2–3 段“高光聊天脚本”**（每段 4–6 句即可）：
  - *示例方向*：一段傲娇/撩人的早晚安问候 + 一段突发斗图（触发构造状态气泡与灵犀微动效）。
- [ ] **编写 1 份“高甜情侣手账/愿望清单”文案**：用于翻页手账和愿望清单特写镜头，避免真实隐私内容入镜。

### 4. 音频与配音准备
- [ ] **BGM 选曲（1 首主曲，约 70 秒）**：
  - 建议结构：前 15 秒轻柔铺垫（古筝/钢琴/风铃环境音）→ 15 秒处鼓点切入（轻快新中式或 City-Pop 律动）→ 结尾 8 秒留白收束。
  - 若用于公开发布，请确认使用**免版权音乐 / CC0 协议音乐 / 平台自带曲库**。
- [ ] **是否需要配音**：纯文字花字 + UI 音效（推荐，制作周期短、不挑声线） vs AI/真人旁白。

### 5. 版权与免责声明文案
- [ ] 准备片尾统一声明文字，例如：*“本作品为《代号鸢》同人向网页交互项目演示，非官方应用；涉及 AI 对话功能需自备接口，仅作个人学习与兴趣交流。”*

## 五、技术实施路线（如何高效生产成片）

为了保证成片**画面清晰（无录屏压缩糊感）、操作零失误、可随时修改重录**，推荐采用以下双轨技术方案：

### 方案 A：自动化实机录屏 + 后期合成流水线（最推荐）
1. **第 1 步：搭建隔离的演示环境**
   - 在本地启动静态服务，注入 `demo_seed.js`（仅作用于演示会话，自动写入预设壁纸、名士数据、对话剧本、手账内容，并拦截真实网络请求返回预设好的毫秒级丝滑响应）。
2. **第 2 步：Playwright 剧本化录制**
   - 编写 Node.js / Python Playwright 脚本，按分镜表精确控制鼠标轨迹、滑动速度、停留时长，逐幕导出无损/高码率视频片段（`shot_01_lockscreen.webm` ~ `shot_06_ending.webm`）。
3. **第 3 步：手机样机包装与合成**
   - 使用 HTML/CSS 样机壳或 FFmpeg 脚本为录屏套上精致边框、动态花字，输出**粗剪成片**；你只需在剪映中替换最终 BGM 并微调卡点即可发布。

### 方案 B：纯前端动态展示页（HTML5 / Remotion 路线）
- 如果你希望宣传片不仅能导出视频，还能直接作为**项目官网的交互式介绍页**，我可以用 React + CSS 动画 / Remotion 构建一个“网页版宣传片”，内置手机框与自动播放的时间轴动画，既可在线播放，也能一键录屏导出为 MP4。
